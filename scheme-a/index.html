1. CRM 挂载位置

  • 产品名：武汉电销系统 / 重洋启思电销系统，路径前缀 /WH_CRM_v2/
  • 复用 数据池 dataPool；分配 distribute；企微布局参考 weworkBot/globalConfig / 渠道活码成员
  • 新增 侧栏「AI外呼中心」：AI任务 · 任务明细 · 企微承接账号 · 看板 · 通话明细 · 系统说明
  • 原「AI专属外呼池 / 外呼策略配置 / 意向线索池 / 外呼任务监控」已合并进 AI任务 + 任务明细

2. 主流程

创建AI任务 → 按线索分配比例抽池 → 外呼 → 加微 → 任务明细批量分配
flowchart TD
  A[数据池 dataPool 未领取线索] --> B[新建AI外呼任务]
  B --> B1[线索分配比例 公海池分层A-E合计100]
  B1 --> B2[并发独占 / 任务时间 / 禁拨时段]
  B2 --> C{按分层比例抽取 A-E}
  C -->|占比0或强制剔除| Z1[回数据池或标记不可呼]
  C -->|通过| D[任务明细客户列表]
  D --> E[调度拨打 火山/阿里]
  E --> F{接通?}
  F -->|未接通| G[未接再呼]
  G --> E
  F -->|接通| H[AI意向识别]
  H --> I{意向达标?}
  I -->|否| J[回写总结 冷却]
  I -->|是| K[承接账号轮询加微]
  K --> L[任务明细 · 意向待分配]
  L --> M[批量/单条指定承接人分配]
  M --> N[客户池 来源=AI机器人]
  N --> O[不占未拨打领取额度]

3. 线索状态机

任务明细内状态
stateDiagram-v2
  [*] --> 未领取公共
  未领取公共 --> 待呼: 任务按比例抽取
  待呼 --> 外呼中: 任务拨打
  外呼中 --> 未接通待重播: 未接通
  未接通待重播 --> 外呼中: 再呼
  外呼中 --> 意向待分配: 意向达标
  意向待分配 --> 已加微: 加微同意
  已加微 --> 已分配: 指定承接人入库
  已分配 --> [*]

4. 配置要点

  • 线索分配比例：对齐公海池分层 A/B/C/D/E %（默认 5/15/5/5/70），合计必须 = 100%；与准入合并，按分层占比从数据池抽取；计划外呼量与比例分离
  • 时间：任务时间区间 + 禁拨时段；政策 21:00–次日 09:00 不可外呼
  • 并发：可分配机器人并发/总并发，独占模式，任务并发 1–可分配上限
  • 加微：初始化仅轮询；配置加微昵称、邀请通知模版、通过欢迎语、失败重试
  • 承接成员：组织架构筛选弹窗多选，展示对齐渠道活码

5. 验收要点

  • 创建任务时公海池分层比例（A–E）合计 ≠100% 不可提交
  • 任务明细可按任务切换，意向与池内客户同表，支持批量指定承接人
  • 企微承接为列表模式：组织架构快速筛选 + 云设备在线状态；仅在线可添加/开启承接，离线默认不承接；加微策略固定轮询
  • 看板 / 通话明细列表基础字段统一：通话ID · 洋葱ID · 外呼手机号
  • 分配入库后来源=AI机器人，额度豁免正确
